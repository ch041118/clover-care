# 일시별 보호사 선택

- 조율 일시(한국 시간)를 먼저 선택한 후 해당 시간에 가능한 승인된 보호사를 서버에서 조회한다. 녹음 해석 요청은 돌봄 종류도 먼저 선택한다.
- 돌봄 전체 소요 시간, 근무 요일·시간, 제공 서비스, 보호사와 어르신의 예약, 앞뒤 30분 이동 여유를 확인한다. 자동 배정의 거리 제한은 기존대로이며 수동 조율에 새 거리 제한을 추가하지 않는다.
- 가능한 후보만 이름·근무 지역으로 검색한다. 이름순으로 최대 100명을 표시하고 후보가 많으면 검색으로 좁히도록 안내한다. 보호사를 자동 선택하지 않는다.
- 일시·서비스 변경 시 기존 선택을 비우고 다시 조회한다. 늦게 도착한 이전 응답은 적용하지 않는다. 후보 없음·조회 실패를 구분하며 실패 시 재조회할 수 있다.
- 저장할 때도 동일한 서버 규칙으로 재검사하므로 조회 후 다른 예약이 들어오면 중복 배정을 거부한다. 해당 경우 일시를 변경하여 다시 조회한다.
- 자동 테스트 250개 통과. 가상 직원 화면에서 일시 선택 후 후보 2명, 지역 검색 후 1명 표시를 확인했다. 실제 일정은 변경하지 않았다.
