# 이 PC에서 직접 켜고 끄기

자동 실행, 작업 스케줄러, Windows 서비스, 자동 재시작은 등록하지 않습니다.

## 같은 Wi-Fi

프로젝트의 `Start-LAN.cmd`를 더블클릭합니다. 실행창에 나온 주소를 같은 와이파이의 다른 기기에서 엽니다. 기존 서버가 이미 켜져 있으면 먼저 그 창에서 Ctrl+C로 종료합니다. 실행창에서 Ctrl+C로 종료하며, 재부팅 후에는 직접 파일을 다시 실행해야 합니다.

## 비용 없이 다른 Wi-Fi에서 접속

무료 ngrok 계정의 할당된 HTTPS 도메인을 사용합니다. 서버 실행과 데이터 저장은 이 PC가 담당하고 ngrok를 통해 외부 요청이 전달됩니다. 도메인을 구매하지 않습니다.

1. [ngrok 무료 가입](https://dashboard.ngrok.com/signup) 후 [Windows 설치 안내](https://ngrok.com/downloads/windows)를 따라 설치합니다. 인증 토큰은 본인 PC의 ngrok 설정에 등록하고 채팅이나 코드에 적지 않습니다.
2. ngrok 대시보드의 Domains에서 본인에게 할당된 무료 도메인을 확인합니다.
3. `deploy/public.env.example`을 프로젝트 루트의 `.env.public`으로 복사하고 `PUBLIC_ORIGIN`에 실제 `https://...ngrok-free.app` 또는 `https://...ngrok-free.dev` 주소를 입력합니다.
4. 외부 공개 전에 로컬 앱의 ‘내 계정’에서 `adminpassword`를 바꿉니다. 실행 파일이 알려진 기본 관리자 비밀번호가 남아 있으면 공개를 중단합니다. 계정 비밀번호를 자동으로 바꾸지는 않습니다.
5. 기존 로컬/LAN 서버 창에서 Ctrl+C로 종료하고 `Start-Public.cmd`를 더블클릭합니다. ngrok 연결 성공을 확인한 뒤 표시된 HTTPS 주소의 `/app/`으로 접속합니다.
6. 사용을 마치면 실행창에서 Ctrl+C를 누릅니다. 서버와 외부 연결을 함께 종료하며 자동으로 다시 켜지지 않습니다.

`npm run start:public -- --check`는 설정만 확인하고 외부 연결을 열지 않습니다. `NGROK_PATH`에는 ngrok.exe의 전체 경로를 지정할 수 있습니다. ngrok 설치·계정·도메인 연결 전에는 실제 외부 URL이 생성되거나 연결된 것으로 표시하지 않습니다.

## 무료 이용 범위

현재 공식 무료 요금제에는 계정에 할당된 HTTPS 개발 도메인 1개가 포함됩니다. 월 외부 전송량 1GB와 HTTP 요청 20,000회 제한이 있고 브라우저의 첫 방문 안내 화면이 표시됩니다. 본 앱의 주기적 화면 새로고침도 요청량에 포함되므로 다수 사용자의 상시 운영에 충분하다고 보장할 수 없습니다. 한도를 넘겨도 이 실행 파일은 결제하거나 유료 요금제로 바꾸지 않습니다.

[ngrok 공식 무료 제한](https://ngrok.com/docs/pricing-limits/free-plan-limits)

## 실제 서비스의 남은 연결

외부 주소 연결만으로 음성·자동 배정·푸시가 완성되는 것은 아닙니다. STT, 로컬 LLM, 네이버 키, 휴대폰 푸시를 각각 연결해야 합니다. 사회복지사 공개 가입은 관리자 승인 후에만 이용할 수 있습니다. 관리자는 신청자의 신원을 확인한 뒤 승인합니다. 현재 저장된 가상 인물·일정과 실제 운영 데이터의 전환도 별도 작업입니다. `.env.public`의 `CLOVER_DATA_DIR`로 새 저장소를 지정하면 운영 모드에서는 빈 데이터로 시작하며 기존 계정은 복사되지 않습니다.

PC를 끄거나 절전 상태로 두거나 서버 실행창을 종료하면 접속과 안부 알림 작업이 중단됩니다. 전원·절전·방화벽 설정은 자동으로 바꾸지 않습니다.
