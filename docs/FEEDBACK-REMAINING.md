# 미구현·미완료 항목

- **기관 관리자·팀장·직원 계층**: 기관 내 팀 구성, 기관 관리자와 팀장의 승인·권한 위임, 소속 변경 관리. 현재 기관별 데이터 분리만으로 이 계층이 구현된 것은 아니다.
- **주소 검색 결과 자동 입력**: 비서가 찾은 주소를 등록·수정 화면에 채우고 사용자 확인 후 저장하는 연결 과정.
- **오프라인 체험 모드의 새 기능 연동**: 기기 내 체험 저장소에는 비서 도구와 요청 내용 확인·확정 일정 확인·변경 요청 API가 연결되지 않았다. 서버 연결 모드와 기능 범위가 다르다.
- **처리 계층별 동시 부하 검증**: 웹 화면 제공, 일반 HTTP API, LLM·에이전트, STT 각각의 동시 요청·대기열·실패율·처리 한계 측정. 이번 메모리 조회 성능 비교만으로 동시 사용자 수를 판단할 수 없다.
- **실제 사용 환경 검증**: 실제 어르신 발음·주변 소음이 포함된 음성 평가, 실제 Android/iPhone에서 마이크·스와이프·푸시 검증, 실제 Chrome/Safari 점검. 자동 테스트 및 Edge Chromium·Playwright WebKit 검증과 구분한다.
- **회의에서 검토 후보로 언급한 모델·클라우드 연결**: Bedrock·AgentCore 전용 연동, 국내 모델 및 대체 STT의 비교 평가·교체는 미완료다. 특정 공급자 도입이 확정된 요구는 아니므로 기관 조건 확인 후 결정해야 한다.
