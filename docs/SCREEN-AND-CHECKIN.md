# 화면 설정과 요청 당일 안부 확인

- 요약의 접수된 돌봄은 완료 전 요청(수락 대기·확정·조율 필요)만 표시한다. 각 상태 카드는 해당 상태 목록으로 연결하며 제목·건수·이름 검색·자동 갱신에 같은 범위를 적용한다. 완료 카드는 최근 3일 목록으로 연결하고 전체 처리 내역은 별도 링크로 제공한다.
- 직원이 로그인 유지 상태로 다시 열면 돌봄 한눈에에서 시작한다. 어르신은 마이크 화면을 유지한다. 백그라운드에서 돌아올 때도 직원은 요약으로 이동하되 열어 둔 상세·입력창이 있으면 보존한다.

- 실제 돌봄 요청을 접수한 날은 한국 날짜 기준으로 출석·안부 확인을 생략한다. 요청한 돌봄의 예정일이 내일이어도 오늘 요청을 접수했으면 오늘의 활동으로 인정한다. 시연 요청은 제외한다.
- 이미 시작된 안부 확인은 남은 질문과 대기 중 알림을 중지한다. 이미 사회복지사에게 올라온 우려·미응답 기록은 자동으로 지우지 않고 담당자가 확인할 수 있게 보존한다. 이미 발송된 기기 알림을 회수하는 기능은 아니다.
- 다음 날 새 활동이나 요청이 없으면 기존 정책대로 저녁 안부 확인을 진행한다.
- 사회복지사·요양보호사·관리자 화면 상단의 다크 모드/라이트 모드 버튼으로 전환한다. 같은 브라우저·기기에서 계정별 선택을 기억한다. 다른 기기로 자동 동기화하지 않는다. 어르신 화면과 로그인 화면은 밝은 화면을 유지한다.
- 검증: 전체 자동 테스트 231개 통과. 가상 직원 화면을 모바일 너비의 브라우저에서 전환하고 새로고침 후 유지되는 것을 확인했다.
