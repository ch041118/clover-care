# 클로버 켜기 / 끄기

바탕화면의 **클로버 켜기·끄기** 바로가기를 실행하세요.

- 꺼져 있으면 서버, 로컬 AI, 음성 인식, 외부 접속을 함께 시작합니다. 준비되면 브라우저에 클로버가 열립니다.
- 켜져 있으면 같은 아이콘으로 클로버 실행기와 하위 프로그램을 모두 종료합니다. 저장된 데이터는 유지됩니다.
- 시작 중에 다시 실행하면 시작을 취소하고 종료합니다. 준비 중에는 잠시 기다려 주세요.
- 컴퓨터를 재시작하면 꺼진 상태입니다. 자동 실행이나 자동 재시작은 설치하지 않습니다.

Windows 기본 설정에서 바탕화면 바로가기는 더블클릭으로 실행합니다. 작업 표시줄에 고정하면 한 번 클릭해 사용할 수 있습니다.

프로젝트 폴더의 `Clover.cmd`도 같은 기능입니다. 기존 `Start-Public.cmd`로 별도 실행한 서버는 먼저 기존 창에서 종료하세요.

실행 오류는 안내창에 표시됩니다. 상세 기록은 `data/launcher-logs/`에 저장되며 다음 실행 때 덮어씁니다. 로그는 개인정보가 포함될 수 있으므로 외부에 그대로 공유하지 마세요.

설치된 Node.js, 프로젝트 폴더, 기존 ngrok 설정과 인터넷 연결이 필요합니다. 폴더를 옮기면 바로가기 대상도 수정해야 합니다.

실행기의 PID뿐 아니라 실행 시각과 명령 경로를 함께 확인하므로 재부팅 후 남은 상태 파일 때문에 다른 프로그램을 종료하지 않습니다. 종료는 이 실행기가 시작한 프로세스 트리에만 적용됩니다.
