# 요양보호사 승인과 돌봄 한눈에

- 요양보호사와 사회복지사는 가입 신청 후 관리자가 승인해야 로그인할 수 있다. 가입 응답에는 로그인 쿠키나 앱 토큰이 발급되지 않는다.
- 관리자 로그인 → 내 계정 → 요양보호사 가입 승인에서 신청자를 확인하고 승인한다. 사회복지사와 요양보호사는 다른 가입자를 승인할 수 없다.
- 기존 보호사 계정 중 승인 기록이 없는 계정도 승인 대기로 전환된다. 해당 계정의 로그인 세션, 어르신 연결 세션·코드, 기기 알림 권한이 회수된다. 승인 후 다시 로그인하고 필요한 어르신 기기를 연결한다. 기존 요청과 처리 내역은 유지된다.
- 미승인 보호사는 자동 배정 및 수동 일정 조율의 배정 대상에서 제외된다.
- 돌봄 한눈에의 완료 요청은 한국 날짜 기준 오늘 포함 최근 3일만 표시한다. 실제 완료 시각을 저장하며, 기존 기록은 완료 이벤트 또는 일정 종료 시각을 사용한다. 진행 중·수락 대기·조율 필요 요청은 기간과 관계없이 유지한다. 전체 완료 기록은 처리 내역에서 조회할 수 있다.
- 검증: 자동 테스트 237개 통과. 승인 전 로그인·권한 위조·기존 세션·자동/수동 배정·승인 후 로그인·한국 날짜 경계와 전체 기록 보존을 포함한다.
