# 2026-10-05 최적화

- 첫 화면의 정적 HTML·CSS·실행 파일 조합과 보안 해시, gzip 결과를 서버에서 한 번 생성해 재사용합니다. 파일 변경 시 갱신하며 인증된 API 데이터는 캐시하지 않습니다.
- 화면 파일 읽기와 압축을 비동기로 수행합니다. 동시에 접속해도 같은 생성 작업을 공유합니다.
- gzip을 지원하는 접속에만 압축 화면을 전달합니다. 브라우저의 첫 화면 저장 정책은 기존 no-store를 유지합니다.
- 웹·모바일 실행 파일을 축소했습니다. Safari 15 / Chrome 109 지원 기준은 그대로입니다.
- 숨겨진 어르신 화면은 주기적 조회를 중지합니다. 느린 응답 중에는 주기 조회가 중첩되지 않고 실패 후에는 다시 시도합니다. 서버의 안부 확인 작업은 유지됩니다.
- 수동 실행하는 로컬 Ollama의 기본 모델 유지 시간을 60초로 줄였습니다. 메모리 해제 후 다음 요청은 다시 모델을 불러오는 시간이 필요합니다. OLLAMA_KEEP_ALIVE 설정이 있으면 해당 값을 우선합니다. 음성 인식 모델은 응답 속도를 위해 유지합니다.
