# 어르신 SOS와 담당 보호사 전화

- 어르신 화면의 SOS 버튼은 녹음·AI 없이 즉시 서버에 긴급 요청을 접수한다. 서버 응답이 성공한 뒤에만 접수됐다고 표시한다. 전송 실패 시 재시도 및 전화 안내를 표시한다. 미완료 SOS가 있으면 반복 클릭·새로고침 후 재전송해도 같은 요청을 반환한다.
- SOS는 119 신고·자동 출동이 아니다. 어르신에게 이 점과 별도의 119 전화 버튼을 표시한다. 전화 버튼은 휴대폰 전화 앱을 열며 실제 통화 연결 여부는 앱에서 확인하지 않는다.
- 직원 화면의 모든 페이지 상단에 미완료 SOS가 표시된다. 사회복지사·관리자와 해당 보호사가 연락 및 조치 내용을 적고 대응을 완료한다. 일반 일정으로 자동 배정하지 않는다. 내역은 보존한다.
- 승인된 등록 담당 보호사를 우선 사용하고, 없으면 현재 진행 중이거나 앞으로 예정된 가장 이른 확정 일정의 승인된 보호사를 사용한다. 과거 일정 또는 미승인 계정의 번호는 노출하지 않는다.
- 보호사 회원가입 또는 내 근무 설정의 연락받을 전화번호에서 등록·수정한다. 기존 계정에는 번호가 없을 수 있으며, 이 경우 어르신 화면에 등록 필요 안내가 나온다. 가짜 번호는 채우지 않는다.
- SOS 푸시 작업은 사회복지사·관리자와 담당 보호사의 직원 기기에만 전달된다. 보호사 계정으로 연결한 어르신 기기에는 직원 알림을 보내지 않는다. 등록 기기나 FCM/APNs 설정이 없으면 전송 실패를 기록한다. 푸시 서비스의 접수는 사람이 확인했다는 의미가 아니다. 현재 실제 푸시 전송·실제 전화 통화는 검증하지 않았다.
- Expo 앱에는 SOS 경로 허용과 전화 앱 실행 기능이 추가되어 재빌드한 앱이 필요하다. Expo Go에서도 화면·SOS 접수·전화 앱 실행을 시험할 수 있으나 원격 푸시는 지원하지 않는다.
- 검증: 자동 테스트의 중복 접수, 계정별 접근, 전화번호 검증·격리, 알림 수신자, HTTP 접수·대응 저장·재시작 확인 및 격리된 가상 어르신 화면의 SOS 클릭 검증. 실제 사용자에게 테스트 알림이나 전화를 보내지 않았다.
