# 어르신 목록과 상세정보

- 어르신 관리는 이름순 행 목록이 기본이며 25명씩 페이지를 나눈다. 이름·주소·보호자 연락처 검색과 특이/주의 사항 있음, 확인 필요, 진행 중, 기록 없음 필터를 함께 적용한다. 상세정보를 닫거나 저장해도 검색 조건을 유지한다.
- 행 클릭, 상세정보 버튼 또는 키보드 Enter/Space로 상세 카드를 연다. 기본 정보, 특이·주의 사항, 열람 가능한 최근 돌봄 20건과 요청별 처리 내역을 확인한다. 요양보호사는 기존 계정 범위에 속하는 기록만 보며 전체 기관 기록으로 권한을 확대하지 않는다.
- 사회복지사·관리자와 등록 담당 보호사, 현재 수락 대기/확정 일정의 승인된 보호사는 특이·주의 사항을 수정할 수 있다. 과거 일정만 있는 보호사는 읽기만 가능하다. 어르신 계정의 상태 응답에는 직원 메모를 포함하지 않는다.
- 각 항목은 3,000자 이내다. 수정자·시각·변경 이력을 서버에 보존하고, 동시에 편집한 경우 뒤늦은 저장으로 앞선 수정을 덮어쓰지 않도록 버전을 검사한다. 변경 이력 전체는 일반 상태 응답에 포함하지 않는다.
- 목록 필터·3,000명 검색·권한·동시 수정·HTTP 저장·서버 재시작 후 보존 테스트를 포함해 총 253개 자동 테스트 통과. 격리된 가상 데이터 화면에서 검색·행 선택·메모 저장을 확인했다. 실제 어르신 정보는 수정하지 않았다.
- 현재 목록은 기존 계정별 상태 조회 결과에서 검색·페이지 분할한다. 서버에서 전체 데이터를 페이지별 조회하는 방식은 아니다.
